# Executive AI Consultancy

Premium Next.js website for an AI consulting studio focused on strategy, agent development, automation, enterprise AI, RAG, chatbots, SaaS, and cloud delivery.

## Run locally

```bash
npm run dev
```


Open `http://localhost:3000` in your browser.

If you are starting from the workspace root, first `cd /home/raish/raish/executive-ai-consultancy`.

## Main routes

- `/`
- `/about`
- `/services`
- `/solutions`
- `/industries`
- `/case-studies`
- `/blog`
- `/resources`
- `/contact`
